# Kate AI Assistant

Kate AI – Short Summary
ROLE:
Build a modern, responsive AI productivity website as an expert AI developer and UI/UX designer.
OBJECTIVE:
Create Kate AI, an AI assistant that helps users with research, workplace questions, and professional emails.
CONTEXT:
Kate AI has three main tools:
AI Research Assistant
Summarize topics and articles.
Extract key points.
Provide insights and recommendations.
AI Chatbot
Act as an interactive workplace assistant.
Answer user questions and prompts.
Maintain conversation context.
Respond as Kate.
Smart Email Generator
Create professional emails.
Support Formal, Friendly, and Persuasive tones.
Allow users to edit, copy, and regenerate emails.
Kate's email: nkhensokate@gmail.com
REQUIREMENTS:
Modern and professional design.
Responsive on desktop, tablet, and mobile.
Simple navigation between the three tools.
Real AI functionality through an AI model/API.
Loading and error states.
Copy buttons for generated content.
No login, signup, logout, forgot-password, or user-account features.
OUTPUT:
Build a complete, functional Kate AI Productivity Assistant with a dashboard, Research Assistant, AI Chatbot, and Smart Email Generator.
